# EX No.3.2. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION

## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1. Create the Base Sketch: Open Fusion 360, select the XY plane and create a new sketch. Draw a horizontal centre line and mark the overall length as 420 mm using the Dimension tool.

2. Draw the End Circles: Create two circles at both ends of the base with a centre-to-centre distance of 300 mm. Apply a radius of R60 mm to the outer rounded ends.

3. Create the Base Profile: Connect the two end circles using straight lines and use the Trim tool to remove unwanted inner portions, forming an elongated rounded base profile with an overall length of 420 mm.

4. Create the Mounting Holes: Draw two holes at the centre of both rounded ends and apply a diameter of Ø40 mm. Use the Dimension tool to position them accurately with 300 mm centre distance.

5. Draw the Central Hole: Create another circle at the centre of the base and apply a diameter of Ø20 mm. Use the centre lines to maintain proper alignment.

6. Extrude the Base: Finish the sketch, select the closed base profile and use the Extrude command to give it the required thickness according to the drawing.

7. Create the Curved Bridge Profile: Select the front plane and draw the raised curved portion using the Arc tool. Apply a radius of R110 mm and use straight lines to connect the curved portion to the base.

8. Apply Bridge Dimensions: Use the Dimension tool to set the bridge height as 110 mm and its width as 150 mm, following the front and side views of the drawing.

9. Extrude the Curved Portion: Finish the bridge sketch and use Extrude to extend the curved profile across 150 mm width. Select Join to connect it with the base.

10. Final Trimming and Finishing: Use the Trim tool to remove unwanted sketch portions, check the Ø40 mm and Ø20 mm holes, inspect the R60 mm and R110 mm curves, and finish the model using Fillet if required.
